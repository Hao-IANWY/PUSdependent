# chloroplast_site_overview — Overview of chloroplast Ψ sites in WT leaf

## Purpose

Quantify Ψ sites and characterize modification fraction distributions across chloroplast rRNA, tRNA, and mRNA in WT leaf tissue, generating an individual density plot for each RNA class.

## Inputs

- `polyARNA/STAT/fisher/rRNA/WT-leaf_sites.positive.tsv`
- `tRNA/STAT/fisher/ncRNA/WT_Leaf_sites.positive.tsv`
- `polyARNA/STAT/fisher/mRNA/WT-leaf_sites.positive.tsv`

## Filtering Rules

- rRNA: `chr == "Ch23S"`
- tRNA: `chr` starting with `tRNA-Pt-`
- mRNA: `chr` starting with `ATCG`
- Retain sites with finite `ratio` values within [0, 1], displayed as percentages (0–100%)

## Data Summary

| RNA | Site count |
|---|---|
| rRNA | 4 |
| tRNA | 64 |
| mRNA | 18 |

## Outputs

- `chloroplast_site_overview_density_sites.tsv`: Merged site table across all three RNA classes (`rna_type, chr, pos, strand, ratio, depth, ratio_pct, site_id`)
- `chloroplast_site_overview_count_summary.tsv`: Site counts per RNA class
- `chloroplast_site_overview_density_{rrna,trna,mrna}.pdf/png/svg`

Plot annotation: x-axis = modification fraction (0–100%), y-axis = density, with `n = <site count>` annotated inside the curve. The upper y-axis limit is generated by `y_axis_cover()` to fully enclose the density peak.

## Usage

```bash
bash data.sh
```
