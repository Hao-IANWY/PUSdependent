# chloroplast_purified_rna_validation — Chloroplast-purified RNA site counts and overlap validation

## Purpose

Quantify Ψ sites detected across chloroplast rRNA, tRNA, and mRNA using sequencing libraries prepared from purified chloroplast RNA, and perform overlap validation against WT leaf poly(A)+ and small RNA datasets (rRNA and mRNA against poly(A)+; tRNA against small RNA).

## Inputs

- `Chloroplast/STAT/fisher/ncRNA/Chloroplast_sites.positive.tsv`
- `Chloroplast/STAT/fisher/mRNA/Chloroplast_sites.positive.tsv`
- `Figures/chloroplast_RNA/chloroplast_site_overview/chloroplast_site_overview_density_sites.tsv` (WT leaf reference set, generated by `chloroplast_site_overview/data.sh`)

## Filtering Rules and Overlap Criteria

- rRNA: retain `chr == "Ch23S"` from ncRNA results
- tRNA: retain `chr` starting with `tRNA-Pt-` from ncRNA results
- mRNA: retain `chr` starting with `ATCG` from mRNA results
- Site identifier: `chr:pos:strand`; overlap requires an exact match

## Data Summary

| RNA | Purified RNA | WT leaf | Overlap | Purified RNA coverage | WT coverage |
|---|---|---|---|---|---|
| rRNA | 3 | 4 | 3 | 100.0% | 75.0% |
| tRNA | 59 | 64 | 55 | 93.2% | 85.9% |
| mRNA | 15 | 18 | 11 | 73.3% | 61.1% |

## Outputs

- `chloroplast_purified_rna_validation_sites.tsv`: Filtered site table from purified RNA
- `chloroplast_purified_rna_validation_count_summary.tsv`: Site count summary
- `chloroplast_purified_rna_validation_overlap_summary.tsv`: Overlap summary (including `purified_only_sites`, `leaf_only_sites`, and bidirectional coverage)
- `chloroplast_purified_rna_validation_barplot.pdf/png/svg`
- `chloroplast_purified_rna_validation_overlap.pdf/png/svg`: Three 2-set Venn diagrams for rRNA, tRNA, and mRNA

Venn diagrams are rendered using customized `ggplot2` polygons (`geom_polygon`), supporting empty intersections without failure. Bar plot y-axis limits are computed using `pretty()` to cover the maximum bar height while leaving headroom for numerical labels.

## Usage

```bash
# First run chloroplast_site_overview/data.sh to generate the WT leaf reference table
bash data.sh
```
