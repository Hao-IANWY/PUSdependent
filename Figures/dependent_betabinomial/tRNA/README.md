# dependent_betabinomial/tRNA — Genotype-specific dependent tRNA Ψ site figures

## Purpose

Resolve, for each `trua` mutant, the writer-dependent tRNA Ψ sites across Root / Leaf / Flower: where the sites fall on the canonical tRNA secondary structure, how strongly modification drops in the mutant, and whether the two independent alleles agree.

Cross-genotype summaries (site counts in `sites_count/`, modification-loss effect sizes in `loss_effect/`) live in sibling directories; this directory holds the seven per-genotype figure sets plus the position-level `site_specificity/` group.

## Directory layout

```
Figures/dependent_betabinomial/tRNA/
├── build_genotype_dependent_tables.sh    Shared table-construction logic for all 7 genotypes
│                                         (fix_pos taken directly from upstream Sprinzl_pos)
├── dependent_trna_heatmap_common.R       Shared heatmap implementation (per-tissue + cross-tissue union)
├── dependent_trna_distribution_common.R  Shared Ψ-site distribution boxplot implementation
├── dependent_trna_motif_common.R         Shared motif seqlogo implementation (same site selection
│                                         as the distribution figures)
├── sites_count/                          Cross-genotype: stacked bar of dependent site counts
├── loss_effect/                          Cross-genotype: WT vs mutant modification-fraction scatter
├── motif/                                Cross-genotype: 5-nt context seqlogos per genotype × tissue
├── merge_heatmap/                        Cross-genotype: per-tissue union heatmap over WT + 7 mutants
├── site_specificity/                     Per-position folders: WT-modified nuclear representative
│                                         tRNAs × target mutants (see its README)
└── trua1a/ trua1b/ trua2/ trua3/ trua4/ trua5/ trua6/
    ├── data_prep.sh                      Thin wrapper forwarding to build_genotype_dependent_tables.sh
    ├── plot.R                            Declares the genotype and selects its figure panels
    └── <genotype>_*.{pdf,png,svg,tsv}    Generated outputs
```

Representative tRNAs (highest mean_CPM member of each family) come from
`tRNA/count/ncRNA/family_top/family_top_tRNA.tsv`; no structure-annotation table is stored in this directory.

## Data source and calling criteria

**Sole upstream**: `tRNA/STAT/dependent_betabinomial/ncRNA/<tissue>/<genotype>/`, generated by
`tRNA/STAT/dependent_betabinomial/run.sh` calling `BID-transcript.script/downstream/call_dependent_betabinomial.R`.

A WT-positive site is called dependent when the beta-binomial GLMM (global dispersion θ from a
site-level random intercept, then per-site one-sided test) gives BH q < 0.05 with effect size
`Delta_Ratio(WT-Mut) >= 0.05`, mean Mock depth ≥ 10 in each allele, **and both mutant alleles qualify (AND)**.

- Canonical position `fix_pos` is the upstream `Sprinzl_pos` (canonical 0–76 numbering, added by
  `BID-transcript.script/downstream/tRNA_Sprinzl_annoation/add_sprinzl_pos.py`); no coordinate
  conversion is performed here. Each tRNA copy is annotated with its own segment structure, so copies
  whose length/segment layout differs from the family representative are still positioned correctly.
- Per-allele modification fractions `<g>_1`/`<g>_2` are not in the final dependent table; they are read
  from `<g>_<line>-<tissue>.dependent-sites.tsv` (`Mut_Ratio`, the mean of that allele's three Treat
  replicates over the unfiltered adjustGap pileup).
- The ncRNA reference mixes 220 tRNAs with 287 snoRNAs and 82 snRNAs; rows are therefore filtered
  to `^tRNA-`.

## Usage

Each genotype directory is independent:

```bash
cd trua1a
bash data_prep.sh                       # build tables only, no plotting
Rscript plot.R                          # render figures only
```

`data_prep.sh` produces two tables:

- `<g>_all_tissues.dependent.tsv` — the three tissues stacked, `^tRNA-` only:
  `chr, pos, fix_pos, strand, context, WT_Ratio, Mut_Ratio, Delta_Ratio(WT-Mut), <g>_1, <g>_2, Tissue`
- `<g>_union.dependent.tsv` — cross-tissue union, keeping the observation with the largest Δ per site:
  `…, Tissues, n_tissues, peak_tissue`

`plot.R` reads only these two tables and never touches the raw `tRNA/STAT/` data.

## How to read the figures

**Per-tissue heatmap** (all 7 genotypes; `<g>_delta_ratio_tissue_split_dependent_trna_heatmap`)

- Rows = tissue × tRNA family, blocked by Root / Leaf / Flower (tissue marked by side colors);
  family = compartment + amino acid + anticodon, representative from `family_top` (highest mean_CPM).
- Columns = canonical positions 0–76, blocked into p1 / Acceptor stem / D stem-loop / Anticodon
  stem-loop / Variable / T stem-loop / Acceptor stem / CCA (bottom color strip, positions and names).
- Value = `Delta Ratio(WT - Mut)`, `#FFF5EE → #8B0000`; cells without sites are light gray.
- Left color strip = compartment (Cy orange `#D55E00` / Mt blue `#0072B2` / Pt green `#009E73`).
- **All copies of a family enter the plot**: sites are assigned by `chr`; when several copies of one
  (tissue, family, canonical position) combination carry sites, the maximum Δ is shown.

**Cross-tissue union heatmap** (`trua1b` / `trua4` / `trua5`; `<g>_delta_ratio_union_dependent_trna_heatmap`)

- Rows = tRNA families; value = the **largest** Δ of a site across the three tissues (worst case).
- All three compartments (Cy / Mt / Pt) are included.

**Ψ-site distribution boxplots** (`trua1a` / `trua2` / `trua3` / `trua5` / `trua6`)

- x = tissue, y = Ψ modification fraction (%); three groups: WT (gray), `<g>_1` (pink), `<g>_2` (red).
- Points are individual sites; boxes summarize each group. The x axis keeps all three levels
  (Roots / Leaves / Flowers, `drop = FALSE`), leaving a panel empty when a tissue has no dependent site.
- Compartment × position panels:

  | Genotype | Panels | Biological meaning |
  |---|---|---|
  | trua1a | `cy_27_28`, `cy_66_67_68` | TRUA1A cytosolic Ψ27/28 and Ψ66/67/68 |
  | trua2 | `mt_27_28` | TRUA2 mitochondrial Ψ27/28 (tissue-restricted) |
  | trua3 | `cy_38_39_40` | TRUA3 root-specific cytosolic Ψ38/39/40 |
  | trua5 | `cy_28` | TRUA5 cytosolic Ψ28 (first position of the anticodon stem 5' side) |
  | trua6 | `cy_38_39_40`, `mt_38_39_40` | TRUA6 dual-targeted, broad-spectrum Ψ38/39/40 |

  trua5 is shown as the single position Ψ28 rather than Ψ27/28 because trua5 has no dependent site at
  canonical position 27 — only 28 (41 sites: Root 10 / leaf 15 / Flower 16). The effect is large:
  WT ~48–52% → ~13–28% in both alleles, consistent across tissues.

**Site motif seqlogos** (`trua1a` / `trua2` / `trua3` / `trua5` / `trua6`; `<g>_<suffix>_dependent_motif`)

- Input is `<g>_union.dependent.tsv`: cross-tissue deduplication prevents multi-tissue sites from
  inflating information content. Contexts are the 5-nt `context` string; x axis −2…+2 with the modified
  base at 0 (Ψ derives from U and is therefore always read as T).
- Site selection mirrors the distribution figures (compartment × Sprinzl position); site counts are
  written to `<g>_dependent_motif_site_counts.tsv`.

  | Genotype | Panels | Distinct sites |
  |---|---|---|
  | trua1a | `cy_27_28`, `cy_66_67_68` | 41, 19 |
  | trua2 | `mt_27_28` | 9 |
  | trua3 | `cy_38_39` | 22 |
  | trua5 | `cy_28` | 15 |
  | trua6 | `cy_38_39_40`, `mt_38_39_40` | 58, 7 (observed at 39/40) |

## Known benign warnings

- **`font family 'Arial' not found in PostScript font database`**: `ComplexHeatmap::Heatmap()` measures
  text widths without an open graphics device, so R temporarily opens the default pdf device, whose font
  database lacks Arial. Measurements are unaffected (verified identical under cairo), and the shared
  build-once-render-thrice approach keeps PDF/PNG/SVG layouts identical. This specific warning is
  suppressed in the two `*_common.R` files; all other warnings propagate.
- **`Using ragg device as default. Ignoring type and antialias`**: emitted by the shared `save_plot()`;
  PNG rendering uses ragg, and Arial resolves through fontconfig (PDFs embed Arial-BoldMT; SVGs use
  `font-family: "Arial"` throughout).

## Consistency checks

- Row counts of the per-genotype `all_tissues` tables equal `sites_count/dependent_site_count.tsv`
  (179/13/41/62/22/44/183; total 544 = 547 upstream minus 3 sn/snoRNA sites under the `^tRNA-` filter).
- Motif seqlogo site counts match manual compartment × `fix_pos` filtering of the union tables
  (41/19/9/22/15/58/7), and the center base is 100% T in every combination.
